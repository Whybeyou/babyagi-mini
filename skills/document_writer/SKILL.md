# Document Writer

把任务产出写成结构化文档并落盘的技能。

## 流程
1. 先规划文档结构（标题、分节、每节要点）
2. 写完整内容
3. 用 write_file 保存到文件
4. 用 read_file 读回，校验内容是否完整、格式是否正确

## 反模式
- 写完就结束、不读回校验：可能存了一半或格式错乱，必须读回确认
- 一次性塞入无关内容：只写任务要求的东西，不要扩展跑题
- 用 calculator 去算数：计算类需求交给 calculator 技能，别混在这个技能里

## 边界
- 仅适用于"需要产出文档/计划/方案文件"的任务
- 纯计算任务用 calculator，纯读文件任务用 file_reader，不要用这个技能
