# File Reader

读取文件并提取信息的技能。

## 流程
1. 确认文件名是否存在
2. 用 read_file 读取文件
3. 提取关键信息或做摘要

## 反模式
- 读不存在的文件：先确认文件名，避免无效调用
- 大文件全文塞进上下文：只取关键信息或做摘要，避免上下文膨胀

## 边界
- 仅适用于"读取/查阅已有文件"的任务
- 需要写文件用 document_writer，需要计算用 calculator，不要用这个技能
